## 关键点：保证中文不乱码 + 使用方正雅黑

由于“方正雅黑”通常不是系统自带字体（且为商业字体），本环境里未预装。为了**保证最终导出的 PNG 必定使用方正雅黑且不出现乱码**，我提供了字体嵌入渲染脚本。

### 方式 A（推荐）：用方正雅黑导出 PNG（100% 可控）

1. 将你本地的方正雅黑字体文件放到：
   - `poster/fonts/FZYaHei.ttf`

2. 执行渲染：

```bash
python3 poster/render.py
```

输出文件：

- `poster/out/poster.png`

说明：

- `render.py` 会先渲染 `background.svg`（纯图形，无文字），再用 Pillow 以**指定字体文件**绘制中文/英文，从而保证不乱码。

### 方式 B：只用 SVG（字体由打开 SVG 的系统决定）

直接打开：

- `poster/poster.svg`

该 SVG 的字体栈为“方正雅黑优先、缺失则回退到 Noto Sans CJK”等；如果你的系统已安装方正雅黑，直接打开也会显示为方正雅黑。
